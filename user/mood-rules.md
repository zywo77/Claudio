# 情绪-音乐映射规则

## 天气驱动
| 天气 | 推荐风格 | 示例 |
|---|---|---|
| 晴天 | 轻快流行、indie pop、阳光感的歌 | 周杰伦《稻香》、蔡依林《日不落》 |
| 阴天 | 安静钢琴、氛围电子、低饱和度音乐 | 坂本龙一、Ólafur Arnalds |
| 雨天 | 慵懒爵士、治愈民谣、lo-fi hip hop | 房东的猫、Billie Holiday |
| 雪天 | 温暖 R&B、古典、圣诞爵士（冬季） | Norah Jones、温暖的钢琴 |
| 雾天 | 迷幻摇滚、shoegaze、ambient | Sigur Rós |
| 高温 (>35°C) | 清凉电子、chillwave、bossa nova | 小野丽莎 |
| 低温 (<5°C) | 温暖人声、soul、acoustic | Adele、John Legend |

## 情绪驱动
| 用户说 | 推荐方向 |
|---|---|
| "累了" / "疲惫" / "加班" | 治愈纯音乐、慢速民谣、自然白噪音 |
| "开心" / "心情好" / "今天不错" | 高能量流行、舞曲、元气女声 |
| "难过" / "emo" / "伤感" | 先共情（慢歌），问是否想换轻快的 |
| "焦虑" / "压力大" | 古典、自然声、呼吸引导类音乐 |
| "无聊" / "随便" | 探索模式——从没播过的歌单里随机 |
| "想安静" / "别吵" | 纯钢琴 / 环境音乐 / 低音量提示 |

## 时间段权重
- 深夜（23:00-06:00）：所有规则让位于「安静」「不打扰」
- 早上（06:00-09:00）：优先「醒脑」而非「情绪匹配」
- 其他时段：情绪规则 > 天气规则 > 时间规则
