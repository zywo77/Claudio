# 我的作息规律

## 工作日
| 时段 | 时间 | 音乐需求 |
|---|---|---|
| 起床 | 07:00-07:30 | 轻快有活力，帮助醒脑（流行/indie） |
| 通勤 | 08:00-08:40 | 节奏感强但不躁，通勤路上要有精神 |
| 上午工作 | 09:00-11:00 | 纯音乐 / lo-fi / 钢琴，不打扰专注 |
| 午餐 | 12:00-12:30 | 轻松随意，任何风格 |
| 下午工作 | 14:00-17:00 | 氛围电子 / 爵士 / 古典，保持状态 |
| 下班通勤 | 18:00-18:40 | 需要释放——摇滚/流行/想听新歌 |
| 晚间放松 | 20:00-22:00 | 舒缓、治愈、安静的民谣或 R&B |
| 睡前 | 22:30-23:00 | 纯音乐 / 自然白噪音，帮助入睡 |

## 周末
- 睡到自然醒（通常 09:00-10:00）
- 上午：慵懒、不想被打扰，爵士或 lo-fi
- 下午：开放探索新歌、任何风格都可以
- 晚上：视心情而定，可能 party mode 也可能安静看书

## 特殊习惯
- 加班时喜欢有陪伴感的音乐（人声为主），但不要太燥
- 做饭时喜欢放 podcast 或 90 年代老歌
- 下雨天喜欢窝着听民谣和爵士
