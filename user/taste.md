# 我的音乐品味

## 喜欢的
- 风格：华语流行、民谣、独立流行、轻摇滚、R&B、爵士钢琴
- 年代：1990-2010 年华语经典 / 2015-2025 独立音乐
- 歌手：包括但不限于薛之谦、陈奕迅、毛不易、陈粒、五月天、蔡依林
- 场景：深夜 → 安静治愈 / 雨天 → 慵懒爵士 / 早晨 → 轻快流行 / 通勤 → 节奏感强的 indie

## 不喜欢的
- 风格：重金属、喊麦、土嗨 DJ 版 remix
- 过于商业化的流水线情歌
- 歌词空洞的网络神曲

## 特别偏好
- 喜欢有故事的歌词
- 钢琴伴奏加分
- 竹笛/古筝等民乐融合的现代编曲
- 睡前喜欢纯音乐或白噪音
